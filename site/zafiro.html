EL CONCEPTO

Zafiro hace de conector.

Cada runtime se integra mediante una función adaptadora. La aplicación elige el lenguaje y envía el texto de código al adaptador correspondiente.

AUTOMATIZACIÓN DEFENSIVA

También para tareas de ciberseguridad.

Zafiro puede coordinar scripts autorizados para revisar registros, correlacionar alertas y validar configuraciones usando el lenguaje que mejor se adapte a cada tarea.

01

Revisa registros
Resume eventos de autenticación y destaca patrones para que un analista los investigue.

02

Conecta herramientas
Comparte resultados entre scripts Python, JavaScript, Lua y tu aplicación C++.

03

Valida configuraciones
Automatiza comprobaciones defensivas sobre datos y sistemas que tengas permiso de revisar.

!

Zafiro es el puente de ejecución; no incluye un IDS ni un escáner. Sus adaptadores ejecutan código en el mismo proceso y no son un sandbox. Usa solo código confiable y análisis autorizados.

INSTALACIÓN Y DESCARGAS · v0.2.1

De la descarga a find_package.

Instala los adaptadores que necesites y úsalos desde un proyecto CMake independiente.

Código fuente ↓ Paquete Windows x86_64 (.zip) → TGZ Guía completa → SHA-256

01

Instala los adaptadores

CPython es opcional. CMake integra QuickJS-NG para JavaScript.

cmake -S . -B build \
  -DCMAKE_INSTALL_PREFIX=./install \
  -DZAFIRO_WITH_PYTHON=ON \
  -DZAFIRO_WITH_JAVASCRIPT=ON
cmake --build build
cmake --install build
02

Encuéntralos desde tu app

Indica a CMake dónde se instaló Zafiro.

find_package(zafiro 0.2 CONFIG REQUIRED
  COMPONENTS python javascript)
target_link_libraries(mi_app PRIVATE
  zafiro::python zafiro::javascript)
03

Empaqueta para tu sistema

CPack genera ZIP y TGZ versionados con los componentes seleccionados.

cmake --build build --target package

Compila en Windows, Linux o macOS para tu sistema y arquitectura.

✦

El consumidor CMake está incluido. examples/installed-consumer enlaza los adaptadores usando únicamente los targets instalados.
